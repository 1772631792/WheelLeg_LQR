# 串联腿仿真与代码生成

## 使用入口

主窗口右上角点击 **⚙ 设置**，腿型选择“串联腿（二关节开链）”，填写大腿、小腿、有效腿长范围、轮距和力矩限幅。点击“应用到仿真和代码生成”后：

- 左侧页面名称、二维机构、三维底盘、参数导览、关节说明和电机曲线名称立即切换为串联腿，不再显示五连杆 A/B/C/D/E 图形；
- 串联腿显示使用独立的 `simulation/serial_leg_view.py`，五连杆显示仍由 `simulation/robot_view.py` 负责，两种机构不共享连杆拓扑绘制代码；
- 下一次启动 MuJoCo 使用髋—膝—轮的真实二关节开链；
- “生产代码导出”可以生成当前腿型，也可以一次生成两套互不引用的独立代码包；
- 导出的公开输入输出仍是左右轮 + 左右各两个关节，共六路力矩；
- 现有外部 PID 绑定接口保持不变。

## 传感器与电机顺序

串联腿模式下，每侧两个关节依次为髋关节、膝关节：

| 数组索引 | 输入角度/角速度 | 输出力矩 |
|---:|---|---|
| 0 | 左髋 | 左髋 |
| 1 | 左膝 | 左膝 |
| 2 | 右髋 | 右髋 |
| 3 | 右膝 | 右膝 |

角度约定为：髋角零位朝竖直向下，膝角为小腿相对大腿的角度。实车零位和正方向必须在硬件适配层标定。

## 控制路径

```text
髋角/膝角
    → 二连杆正运动学
    → 虚拟腿长、虚拟腿摆角及速度
    → LQR + 可替换外部 PID
    → 支撑力 F、摆腿力矩 T
    → J(q)^T [F, T]
    → 髋/膝目标力矩
```

代码不依赖 MuJoCo、HAL 或 RTOS。串联腿包只带 `src/wlc_kinematics.h` 中的二连杆解算，不含五连杆闭链公式、腿型枚举或运行时切换分支；并联腿包也不包含串联腿公式。两包各自拥有完整生命周期、外部 PID、LQR、限幅、状态机、自测和接入文档。

## 当前边界

串联腿的运动学、刚体接触和力矩映射已经独立实现并有回归测试，但默认 LQR/MPC 增益仍来自工程现有虚拟腿模型。更换连杆质量、质心偏置或惯量后，应重新建立整车动力学并生成对应增益，不能因为站立仿真通过就直接高功率上实车。

架构参考了公开的 RoboMaster 串联腿资料中“离线建模/增益生成、在机状态估计、统一腿抽象”的思路；本工程没有复制其受非商业许可证限制的实现代码。
